# Dr Kamal – Anatomy & Physiology MCQs

Static quiz website (no build step): 21 quizzes × 15 MCQs = 315 questions (RESY 304, respiratory & renal).

## Publish on GitHub Pages
1. Create a repository and upload all files in this folder (keep the folder structure).
2. Repo → **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
3. Your site will be live at `https://<username>.github.io/<repo>/`.

## Edit questions
Questions live in `data/questions.js` (`q` = question, `o` = options, `a` = correct index 0–3, `e` = explanation).
